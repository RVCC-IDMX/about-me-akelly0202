Project Description

This project is my final assignment for Web Development 1. The goal was to build a personal “About Me” website that shows who I am while practicing the core skills I learned this semester. The site includes a biography, a hobbies section, a photo gallery, a blog-style article, and a contact form. I also designed my own logo and turned the navigation into a mobile hamburger menu.

Skills Learned

HTML Structure

I learned how to build and organize a site using semantic HTML. This included working with sections like header, nav, section, article, fieldset, and footer.

Responsive Web Design

I learned a lot while working with media queries. At first, I struggled because changing something in one size would affect another, and I eventually realized my breakpoints were out of order. Fixing that helped everything make more sense. It was a good lesson in how important it is to structure media queries correctly.

CSS Styling

I used CSS to control spacing, colors, layout, and typography. I practiced using flexbox to align items, created boxes with borders and shadows, and worked on adjusting margins and padding to get the layout visually balanced.

Logo Design

I designed my own logo using Figma and exported it as an SVG so it would stay sharp at any size. I added it to my navigation and made sure it resized correctly on different screens.

Navigation + Hamburger Menu

I turned the navigation into a mobile-friendly hamburger menu. This included styling the three-line button and hiding and showing the menu at different breakpoints. I also learned how to use a small JavaScript toggle to open and close the menu.

Image Hover Effects

I added hover effects to the photos in my gallery using CSS. The images scale slightly larger and brighten on hover. This helped me understand how properties like transform, filter, and transition work together to create simple animations.

Blog Article

I wrote a short article explaining what hover effects are and how I used them in my gallery. 

Contact Form

I built a contact form that includes labels, inputs, a fieldset, and required fields. This helped me combine accessibility, structure, and form styling.
